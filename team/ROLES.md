# Team roles (5 people)

Rotate roles every 4 weeks if you want shared skills.

| Role | Owns | Weeks heavily involved |
|------|------|------------------------|
| **Data lead** | Downloads PMData, folder layout, data dictionary | 1–4 |
| **Features lead** | `src/features.py`, nightly aggregates | 3–5 |
| **Modeling lead** | sklearn pipelines, CV, tuning | 6–10 |
| **App lead** | Streamlit UX, model loading | 11–12 |
| **Quality lead** | Metrics plots, slides, README, PR reviews | 5–12 |

## Definition of done (team norm)

- Notebook runs top-to-bottom on Colab with Drive paths documented
- One PR merged to `main` per week
- No raw participant data in git
